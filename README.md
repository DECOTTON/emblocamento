# Emblocamento – Coletor (RSP Cotton)

App offline (PWA) para contar e conferir os fardinhos emblocados pela leitura da etiqueta
(código de barras SAI ou QR code Abrapa), no coletor Chainway C72 ou no celular.

- Carrega o **pacote** gerado no app principal (Fardinhos a emblocar › 📟 Coletor).
- Funciona **sem internet** depois de instalado ("Adicionar à tela inicial").
- Exporta o arquivo de **leituras** para importar no app principal.

Nenhum dado de lotes/fardinhos fica neste repositório: os dados ficam só nos aparelhos.
